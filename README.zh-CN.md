## 🚁 方法简介

![仿真与真实飞行实验概览](assets/overview.png)

我们研究以单目 RGB 相机进行障碍物感知的无人机敏捷飞行。规划器输入为**连续两帧 RGB 图像、两帧之间的具有米制尺度的相对位姿，以及无人机状态**，输出朝向目标点的平滑飞行轨迹。

核心思路是学习服务于轨迹规划的几何表征。训练时，深度专家通过跨模态特征对齐向 RGB 分支传递规划相关的几何知识，辅助粗深度预测进一步约束几何结构。部署时移除深度专家和辅助深度解码器，无需显式重建深度。

模型在 **3D Gaussian Splatting（3DGS）仿真环境**中训练，随后直接部署到真实环境，**无需真实数据微调**。

## 🧠 网络与训练流程

![网络架构与三阶段训练](assets/method.png)

1. **深度规划预训练：** 使用深度观测和轨迹目标训练深度专家及共享规划模块。
2. **跨模态几何监督：** 冻结深度专家和共享规划模块，通过规划特征对齐与辅助粗深度监督训练 RGB 感知分支。
3. **RGB 规划适配：** 冻结 RGB 感知分支，使用轨迹目标优化共享规划模块。

推理时，网络预测多个候选运动基元、选择分数及碰撞代价；先根据分数筛选候选，再结合预测碰撞代价、在线平滑性代价和目标代价选择轨迹。最终轨迹采用单段五次多项式表示。

## 📊 实验结果

### 🌲 仿真消融实验

以下结果对应论文表 I：期望速度为 **6 m/s**，每种方法在每个环境中评估 **40 次**，测试场景未用于训练。平均速度统计包含成功和失败的实验。

| 方法 | 森林成功率 | 工业设施成功率 | 平均成功率 | 平均速度 |
| --- | ---: | ---: | ---: | ---: |
| Depth Oracle | 100.0% | 100.0% | 100.0% | 4.65 m/s |
| RGB Baseline | 72.5% | 32.5% | 52.5% | 4.56 m/s |
| RGB + 特征对齐 | 80.0% | 70.0% | 75.0% | 4.57 m/s |
| 时序 RGB + 特征对齐 | 85.0% | 75.0% | 80.0% | 5.21 m/s |
| **本文方法** | **90.0%** | **92.5%** | **91.3%** | **5.30 m/s** |

Depth Oracle 使用仿真器提供的深度观测，作为特权几何信息下的参考方法；其余方法使用 RGB 观测进行规划。

### ⚡ 实机部署

| 项目 | 配置或结果 |
| --- | --- |
| 机载计算平台 | NVIDIA Jetson Orin NX |
| 视觉传感器 | 单目鱼眼相机 |
| 规划图像 | 640 × 240 柱面投影，视场角 160° × 55° |
| 状态估计 | VINS-Mono，使用标定后的鱼眼图像及 IMU |
| 网络推理耗时 | TensorRT 部署后为 9.5 ms |
| 规划频率 | 15 Hz |
| 实飞最高避障速度 | 约 6.5 m/s |
| 仿真到真实迁移 | 无真实数据微调 |

状态估计、规划和控制均在机载运行。单目相机用于障碍物感知，规划器仍需要状态估计提供的相对位姿与无人机状态。
